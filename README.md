# ZYVV // Truth-Exposure Engine

**The modern internet is an engineered ecosystem of psychological triggers.** 

ZYVV is an AI-native "Digital Armor." We are building a cynical, hyper-analytical layer between the user and the digital content they consume. ZYVV identifies intent—stripping away emotional bait, AI-generated fluff, and engagement-trap tactics—to show the user exactly what is happening beneath the surface of the digital landscape.

The current implementation is the **Portal Generator**: a high-speed, AI-driven interface that forces users to confront their status-quo and reveals three "Hidden Doors" (Conventional, Contrarian, and Alien) to break their mental loops.

## The Architecture of Truth
* **Inference:** [Groq Llama 3.1-8b](https://groq.com) for sub-second, high-agency reasoning.
* **Database:** [Supabase](https://supabase.com) for persistence and behavioral data collection.
* **Communication:** [Resend](https://resend.com) for direct-to-user insight delivery.
* **Frontend:** Next.js + Tailwind (Dark Brutalist Design).

## Core Philosophy
1.  **Anti-Manipulation:** We do not optimize for engagement; we optimize for truth.
2.  **Brutalist Design:** Minimalist, high-contrast, and aggressive.
3.  **High-Agency Output:** Every user interaction must lead to an immediate, actionable cognitive shift.
